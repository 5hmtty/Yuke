# 语键 Yuke

语键是一款 Windows 流式语音输入工具，将自定义发音映射为键盘按键：先录制几遍自己的发音，之后说出命令词，程序通过比对发音按下对应的按键。支持连续输入命令，体感延迟约 0.2 秒。

Yuke is a continuous voice input tool for Windows that maps custom pronunciations to keyboard keys. Record a few takes of each command word, then say the word — Yuke presses the matching key. Supports speaking commands continuously; the perceived delay is about 0.2 s.

## 已知问题 Known Issues

多音节读法可能会连发。
Multi-syllable pronunciations may occasionally trigger multiple times.
